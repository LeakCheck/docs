# LeakCheck API docs

Mintlify documentation for the LeakCheck API (Pro API v2, Public API, Python
wrapper + CLI). Migrated from wiki.leakcheck.io/en/api.

## Local preview

```bash
npm i -g mint
mint dev
```

## Structure

- `docs.json` — Mintlify config (theme, colors, navigation, footer socials)
- `overview.mdx`, `authentication.mdx`, `errors.mdx` — getting started
- `pro-api/` — lookup endpoint, search types, v1 → v2 migration
- `public-api/` — free lookup endpoint
- `tools/` — Python wrapper and CLI
